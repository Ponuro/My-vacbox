# Raspberry Pi 4 как шлюз

Малина становится «входом в чистый интернет»: весь трафик домашних устройств
уходит через неё в туннель. Устройствам ничего ставить не нужно — они просто
используют Pi как шлюз.

## 0. Подготовка малины

- ОС: **Raspberry Pi OS (64-bit)** или Debian 12. 64-bit желателен (быстрее
  шифрование на Pi 4).
- Pi подключена к домашней сети по **кабелю** (рекомендуется) или Wi-Fi.
- Задай малине **статический IP** в домашней сети (в роутере — DHCP
  reservation по MAC, либо статика на самой Pi). Запиши его — пусть будет,
  например, `192.168.1.2`.

## 1. Перенести параметры с сервера

```bash
sudo mkdir -p /etc/my-vacbox
# скопируй сюда файл, который выдал сервер:
sudo cp client-params.env /etc/my-vacbox/client-params.env
sudo chmod 600 /etc/my-vacbox/client-params.env
```

## 2. Установка

```bash
git clone <URL-этого-репозитория> my-vacbox
cd my-vacbox
sudo bash pi/install.sh
```

Скрипт:
- поставит `sing-box` (режим TUN) и `nftables`,
- включит IP-форвардинг,
- поднимет **kill-switch** (при падении туннеля дом не утекает в открытую сеть),
- пустит DNS **внутри** туннеля (DoH) — от подмены DNS и утечек,
- даст автопереключение VLESS → Hysteria2 через селектор `proxy`.

## 3. Направить домашнюю сеть на малину

Два способа — выбери один.

**A. Через роутер (для всего дома сразу).**
В настройках домашнего роутера (раздел DHCP/LAN) поменяй выдаваемые клиентам:
- **Шлюз по умолчанию (Gateway)** → IP малины (напр. `192.168.1.2`)
- **DNS** → IP малины

Переподключи устройства (или подожди обновления аренды DHCP).

**B. Вручную на одном устройстве (для теста).**
На телефоне/ноуте в настройках сети пропиши шлюз и DNS = IP малины.

> Если роутер не даёт менять шлюз в DHCP — можно поднять на малине свой DHCP
> (dnsmasq) и раздавать параметры с неё. Скажи — добавлю скрипт.

## 4. Проверка

С устройства **за малиной**:

```bash
curl https://api.ipify.org      # должен показать IP твоего VPS, а не домашний
```

Проверь, что нет утечки DNS: на любом из сайтов-тестеров DNS должен резолвиться
через сервер в стране VPS.

Проверка kill-switch: на малине останови туннель —

```bash
sudo systemctl stop sing-box
# интернет на устройствах за малиной должен пропасть (это правильно)
sudo systemctl start sing-box
# и вернуться
```

## Диагностика

```bash
systemctl status sing-box my-vacbox-killswitch
journalctl -u sing-box -f          # живой лог
sudo nft list table inet myvacbox  # правила kill-switch
```

Если `curl` показывает домашний IP (трафик мимо туннеля) или `sing-box check`
ругался при установке — пришли вывод `journalctl -u sing-box -n50`, поправлю
конфиг под твою версию.
