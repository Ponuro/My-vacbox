# Выбор VPS

Нужен сервер **за пределами РФ**. Требования минимальные: 1 vCPU, 512 MB–1 GB
RAM, любой объём диска. sing-box почти ничего не ест — упираться будешь только в
канал.

## Критерии

- **Страна.** Бери поближе для низкого пинга и так, чтобы IP не был уже в
  чёрных списках РКН. Обычно хорошо заходят **Нидерланды, Германия, Финляндия,
  Швеция**. Избегай стран с собственной жёсткой фильтрацией.
- **Возможность сменить IP.** Если конкретный IP начнут блокировать — удобно,
  когда провайдер даёт поменять IP за пару кликов/дёшево.
- **Оплата.** Из РФ картой платить сложно — смотри провайдеров с оплатой
  криптой/альтернативными способами.

## Варианты

### $0 — Oracle Cloud Free Tier
Бесплатная ARM-виртуалка (Ampere A1, до 4 ядра / 24 GB RAM в free tier) —
по сути бесплатный VPS навсегда. Минусы: капризная регистрация, иногда просят
карту для верификации, бывают перебои с выдачей инстансов. Если осилишь
регистрацию — лучший бесплатный вариант. Архитектура ARM (`arm64`) — скрипт
её поддерживает автоматически.

### ~$3–5/мес — бюджетные VPS
Куча провайдеров в ЕС с оплатой криптой и почасовой тарификацией (удобно —
можно быстро пересоздать с новым IP). Ищи по запросам «cheap VPS Netherlands
crypto», «KVM VPS Europe». Бери KVM (не OpenVZ) — для TUN и нормальной работы
sing-box.

> Цены и доступность меняются; конкретные бренды тут не называю намеренно —
> проверь актуальные отзывы и способ оплаты из РФ на момент покупки.

## После покупки

1. Выбери **Ubuntu 22.04 / 24.04** или **Debian 12** при создании.
2. Зайди по SSH под root.
3. Если у провайдера есть **внешний firewall** в панели — открой порты
   **TCP 443** и **UDP 8443** (или те, что задашь через `VLESS_PORT`/`HY2_PORT`).
4. Переходи к [server-setup.md](server-setup.md).
