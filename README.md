# my-vacbox

Свой self-hosted обход цензуры/DPI вместо подписки за $100–500/мес.
Аналог «GeoBox»-подобных коробок — **только та часть, что реально нужна для
свободного интернета в РФ**: маскировка трафика под обычный HTTPS, чтобы
ТСПУ (DPI Роскомнадзора) не мог его опознать и зарезать.

> Что сознательно **не** входит в проект: подмена геолокации, фейковые
> Wi-Fi-окружения «под гео прокси», MAC-цепочки и подмена отпечатка браузера.
> Это инструменты обхода антифрода (мультиаккаунты и т.п.), а не цензуры, и для
> задачи «спокойно пользоваться интернетом» они не нужны.

## Почему обычные VPN в РФ не работают, а это — работает

ТСПУ режет не «VPN вообще», а **узнаваемый протокол**: рукопожатия OpenVPN,
WireGuard, IKEv2 опознаются и блокируются. Поэтому спасает не «ещё один VPN», а
**маскирующий транспорт**:

- **VLESS + XTLS-Reality** — трафик выглядит как обычное TLS-соединение к живому
  чужому сайту (напр. `www.microsoft.com`). Сертификат не нужен, отличить от
  настоящего HTTPS практически невозможно. Это основной канал.
- **Hysteria2** — на QUIC/UDP, с обфускацией. Запасной канал на случай, когда
  душат TCP. Переключение автоматическое.

Всё — open-source (ядро [sing-box](https://sing-box.sagernet.org/)).
Платишь только за VPS: ~$3–5/мес, а можно и $0 (Oracle Free Tier).

## Архитектура

```
   [ Телефон/ТВ/ноут ]  ──┐
   [ Телефон/ТВ/ноут ]  ──┤  обычный Wi-Fi/LAN
   [ Телефон/ТВ/ноут ]  ──┘
            │  (шлюз по умолчанию = Raspberry Pi)
            ▼
   ┌───────────────────────┐        VLESS+Reality (TCP/443)
   │   Raspberry Pi 4      │  ════════════════════════════►  ┌─────────────┐
   │   sing-box (TUN)      │        Hysteria2 (UDP) — резерв  │ VPS за гра- │──► чистый
   │   kill-switch + DoH   │  ◄════════════════════════════  │ ницей       │    интернет
   └───────────────────────┘                                 │ sing-box    │
      весь трафик дома                                        └─────────────┘
      уходит в туннель
```

- **DNS** резолвится внутри туннеля (DoH), поэтому подмена DNS не работает и
  утечки DNS нет.
- **Kill-switch** (nftables): если туннель упал — домашние устройства не «утекают»
  в открытую сеть, а просто теряют интернет, пока канал не восстановится.

## Быстрый старт

1. **Берём VPS** за границей → [`docs/vps-providers.md`](docs/vps-providers.md)
2. **Поднимаем сервер** (одна команда) → [`docs/server-setup.md`](docs/server-setup.md)
3. **Настраиваем Pi как шлюз** → [`docs/pi-gateway.md`](docs/pi-gateway.md)

```bash
# на VPS:
sudo bash server/install.sh
# скрипт выдаст файл my-vacbox-client-params.env — переносим его на малину

# на Raspberry Pi:
sudo mkdir -p /etc/my-vacbox && sudo cp client-params.env /etc/my-vacbox/
sudo bash pi/install.sh
```

## Статус

**v0.1** — первая версия под `sing-box ≥ 1.11`. Конфиги валидируются командой
`sing-box check` прямо при установке. Разворачиваем на реальном железе и
дорабатываем по месту (SNI, порты, домен для Hysteria2, автопереключение).
